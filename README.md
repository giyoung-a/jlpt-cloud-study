# JLPT 어휘·문법 연습 서버

Node.js로 실행하는 N5~N1 학습 서버입니다. PowerShell에서 이 폴더를 열고 다음 명령을 실행합니다.

```powershell
node server.cjs
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 포트 변경은 실행 전에 `$env:PORT = '8001'`로 지정합니다.

- 일일 테스트는 한국 시간 날짜와 급수에 따라 어휘 25문항, 문법 25문항을 제공합니다. 날짜가 바뀌면 문항 조합과 순서가 달라집니다. 같은 날짜와 급수에서는 같은 문항을 풉니다.
- 달력에서 이전 날짜를 열 수 있습니다. 진도는 사용 중인 브라우저에 날짜와 급수별로 저장됩니다.
- 상단 단어 암기와 문법 암기에서 날짜별로 단어 150개와 문법 카드 150장을 풉니다. 문법은 문형 설명 75장과 예문 적용 75장으로 구성됩니다. 문법 카드와 일일 테스트의 정답 해설에 문형 및 정답 표현의 히라가나 읽기가 표시됩니다.
- 한 장씩 암기에서는 O·X로 넘깁니다. 한 바퀴가 끝나면 X 카드만 다시 나옵니다.
- 암기 확인은 당일 150장과 이전 날짜에 답을 제출한 카드를 합칩니다. 같은 카드는 한 번만 나옵니다. O·X 진도와 암기 확인 누적 기록은 브라우저에 저장합니다.
- 독해 연습에서는 급수와 날짜별로 20문항을 풉니다. 답을 고르면 지문, 질문과 보기의 한국어 해석 및 정답 근거를 보여줍니다.
- 일일 테스트 채점 후 한국어 해석과 완성 문장 또는 단어의 읽기·뜻이 표시됩니다.
- 모의고사에서 시험 시간과 과락·합격 기준을 급수별로 적용합니다. 하루 1회, 2026년 11월 29일부터 하루 3회입니다. 날짜와 회차별 시험지에는 기존 문제 은행의 어휘·문법과 자체 제작 독해·청해가 들어갑니다.
- 모의고사 성적표는 과락 기준과 총점 합격선까지의 점수 차이를 표시합니다. 영역 기준 5점 이내, 총점 기준 10점 이내를 아슬아슬로 표시합니다. 오답·미응답 해설에서는 문제 원문과 선택한 답, 정답, 해석, 정답 근거를 볼 수 있습니다.
- 청해는 Windows의 일본어 음성으로 재생합니다. 모의 성적은 공식 척도 점수와 달리 영역별 정답률 환산점수입니다. 응시 상태와 성적은 서버의 mock-progress.json에 기록됩니다.
- 자유 연습에서 급수와 영역을 선택하고 여러 회차를 이어서 풀 수 있습니다.
- 문항 은행은 급수별 어휘 39문항과 문법 39문항, 총 390문항입니다. 한자 읽기·표기·뜻과 문법 형태 선택을 연습합니다. 공식 문제집에서 확인한 학습 표현은 풀이 후 출처가 표시됩니다.

문항은 questions.json에서 추가할 수 있습니다. 각 문항에는 고유 ID, level, section, target, prompt, answer, 서로 다른 distractors 3개, explanation, 선택적 source가 필요합니다. 서버 시작 시 문항을 읽습니다. 문항 은행을 편집하면 날짜별 구성이 달라질 수 있습니다.

## 휴대폰 접속

PC와 휴대폰을 같은 공유기에 연결합니다. PC의 IPv4 주소를 지정해 서버를 시작한 뒤 휴대폰의 Safari나 Chrome에서 해당 주소를 엽니다.

```powershell
$env:JLPT_LAN_ADDRESS = '192.168.1.101'
node server.cjs
```

예시 주소는 http://192.168.1.101:8000 입니다. PC의 IP가 바뀌면 환경 변수와 접속 주소도 갱신합니다. Windows 방화벽에서 해당 주소와 포트의 인바운드 연결이 허용되어 있어야 합니다. 일일 테스트 진도는 브라우저마다 저장됩니다. 모의고사 응시와 성적은 서버에 저장되어 같은 서버에 접속한 기기에서 이어 볼 수 있습니다.

## 추가 암기 자료 출처

study-supplement.json은 [OpenJLPT](https://github.com/evanclan/OpenJLPT)의 급수 분류, 단어 표기·읽기, 문형 및 일본어 예문을 일부 선택해 한국어 뜻·해석과 히라가나 읽기를 붙인 자료입니다. 원저작자는 OpenJLPT 기여자입니다. 이 자료 파일은 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 조건을 따릅니다. OpenJLPT 어휘는 [JMdict](https://www.edrdg.org/jmdict/j_jmdict.html)를 참조합니다.

## 외부 공유용 서버

공유 모드는 별도 로컬 포트에서 실행합니다. `JLPT_SHARE_CONFIG`는 충분히 긴 무작위 초대 코드(`code`)와 40자 이상의 16진수 서명 키(`secret`)가 있는 비공개 JSON 파일 경로입니다. 이 파일과 같은 폴더의 `share-guests`에 방문자별 모의고사 진도와 성적을 저장합니다. 서버를 같은 HTTPS 주소에서 사용해야 브라우저의 게스트 세션과 학습 기록을 이어갈 수 있습니다.

외부 공유를 허용한 경우, HTTPS 터널은 공유 모드의 별도 포트만 연결합니다. PC와 공유 서버, 터널이 실행되는 동안 접속할 수 있습니다. 임시 주소는 터널을 다시 시작하면 바뀔 수 있습니다. [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)
